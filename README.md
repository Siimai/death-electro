# death-electro

Amiga demoscene animation built with [Remotion](https://www.remotion.dev/).

## Rendering via GitHub Actions

1. Open the **Actions** tab and select **Render video**.
2. Click **Run workflow** and optionally set the composition ID (default `AmigaDemo`), output filename (default `video.mp4`) and CRF quality.
3. When the run finishes, download the `rendered-video` artifact from the run summary.

Locally: `npm run build`.
